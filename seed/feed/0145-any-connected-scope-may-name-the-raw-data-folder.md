## Problem

Card 0134 said the person scope names the file-store folder for raw data with no
native home. An exobrain shared by several people keeps one folder for all of
them, named in a group or root scope — and an agent reading the rule looked in
the person scope, found nothing, and asked.

## Pattern

The scope whose people share the folder names it and the tool that reaches it in
its `AGENTS.md` — a person scope for a personal folder, a shared scope for one
several people use. Until one does, the agent asks where such a file goes rather
than committing it.
